# Работа с кодом

[English](CONTRIBUTING.md)

Игровые сценарии и внешние входные данные описаны в [инструкции QA](QA.ru.md).

Начните с [BUILDING.ru.md](BUILDING.ru.md). Библиотеки игры и BepInEx — внешние входные данные сборки, в Git их добавлять нельзя. Вывод храните в исключённой папке `outputs/`. Здесь есть игровой C#, встроенные ресурсы и JSON-словари перевода; личных профилей, копий игры, сохранений и редактируемого проекта модели здесь нет.

| Подсистема | Основные классы в src/ |

| Запуск и настройки | BoomboxPlugin, BoomboxConfiguration, BoomboxSettings |
| Звук и библиотека | AudioDeck, MusicLiveStream, MusicPreparation, UserMusicLibrary, BoomboxDesktopCapture |
| Улучшения | BoomboxProgression, BoomboxCassetteProgression, BoomboxCassetteWorkshop |
| Сеть и бонусы | BoomboxNetworkProtocol, BoomboxNetworkHandshake, BoomboxAuraNetwork, BoomboxAuraSources |

Правка должна решать конкретную наблюдаемую проблему. В pull request опишите проблему, изменение и проверку. Для воспроизводимого дефекта добавляйте небольшую осмысленную регрессионную проверку, если она доступна без игры. Тесты загружают настоящую собранную DLL и проверяют улучшения, сохранение настроек, восстановление библиотеки, отмену поиска, представление бонусов, остановку захвата, совместимость необязательного API Extra Slots и затихание мембраны. Подменяется только недоступный внешний API; это не доказательство игрового поведения.

Офлайн-тесты не проверяют рендер интерфейса, захват звукового устройства или настоящую сетевую сессию. Для изменений этих частей опишите соответствующую игровую проверку. Используйте отдельный тестовый профиль и временные сохранения.

Перед коммитом прочитайте diff и список файлов. Не включайте журналы, личные пути, ключи, музыку, бинарные сборки и настройки пользователя. Каждый языковой словарь репозитория должен содержать все ключи и заполненные переводы. Сохраняйте лицензии и атрибуцию. Для сообщений об ошибках используйте issues репозитория, для исправлений используйте pull requests.

## Добавить перевод

1. Создайте, например, `Translations/German.json` с содержимым `{"meta.culture":"de-DE"}`. Имя файла должно совпадать с внутренним названием языка Valheim. Загрузчик берёт название из `Localization.GetSelectedLanguage()` и добавляет `.json`; коды вроде `de` он не преобразует.
2. Запустите `./check-translations.ps1 -Sync` из папки репозитория в PowerShell 7. Команда добавит отсутствующие ключи во все языки со значением JSON `null`, сохранит существующие переводы и проверит словари. Ненулевой код завершения с именами файлов и незаполненных ключей ожидаем, пока каждый `null` не заменён переводом. Переводите значения справа; ключи слева оставляйте без изменений, включая `text.*`, `boombox_*` и `config.*`. Сохраните пробелы в начале и конце строк, подстановки вроде `{0}`, последовательности `\n` и теги оформления. Сохраняйте корректный JSON в UTF-8 и повторяйте ту же команду до успешного результата.
3. Для проверки без пересборки DLL создайте папку `BepInEx/config/ValheimBoombox/Translations` в отдельном тестовом профиле. Поместите туда `German.json`. Этот путь отсчитывается от папки профиля, а не от исходников.
4. Выберите соответствующий язык в Valheim. После изменения файла переключитесь на другой язык и обратно либо перезапустите игру. Загрузчик не отслеживает изменения файлов автоматически.
5. В игре проверьте названия и описания предметов, меню, значения бонусов, подсказки и описания настроек. Убедитесь, что длинные подписи помещаются. Старый или частичный установленный словарь может использовать запасные строки из языка, указанного в `Translations/catalog.json`; это восстановление во время игры не разрешает неполные словари в репозитории. При некорректном внешнем JSON журнал BepInEx содержит путь файла и ошибку, а корректные запасные строки остаются доступны.
6. Отправьте `Translations/German.json` через pull request. `package.ps1` включает всю папку `Translations` в архив выпуска. Установленный словарь находится в `BepInEx/plugins/Rizias-ValheimBoombox/Translations`. Локальный словарь из `BepInEx/config/ValheimBoombox/Translations` перекрывает совпадающие ключи установленного перевода; при проверке перевода из пакета уберите или обновите локальную подмену.

Добавление JSON-файла не добавляет язык в список языков Valheim. Используйте язык, который можно выбрать в игре.

Правьте переводы непосредственно в `Translations/*.json`. Это исходные файлы, а не результат генерации. `Translations/catalog.json` задаёт основной запасной язык, сейчас английский. Каждый языковой файл задаёт `meta.culture` для форматирования чисел. Для нового сообщения добавьте ключ и текст в запасной словарь, запустите `./check-translations.ps1 -Sync`, заполните появившиеся `null` в остальных словарях и повторите ту же команду. В C# используйте `BoomboxText.Get("message.key")` или `BoomboxText.Format("message.key", value)`. Предложения с переменными переводите целиком с подстановками, чтобы переводчик мог менять их порядок. Сохраняемые уведомления храните как `BoomboxMessage` с ключом и аргументами, чтобы они следовали смене языка. Сборка встраивает JSON, а пакет также содержит внешние копии. Дополнительным языкам не нужны ветки C# и экспортёр из исходников.

Синхронизация не копирует английский текст в другой язык и не удаляет устаревшие ключи. Намеренно совпадающий с английским перевод допустим; `null` явно означает отсутствие перевода. Неизвестные ключи сохраняются и выводятся как ошибки для ручного разбора. Пропуски, незаполненные переводы, повторяющиеся ключи, некорректный JSON, неверные типы значений и несовпадающие подстановки проваливают проверку. Без `-Sync` команда `./check-translations.ps1` только проверяет и ничего не записывает. `build.ps1` использует этот режим и останавливает сборку при ошибках перевода. Изолированные проверки команды без игры запускаются через `./tests/offline/TranslationSyncChecks.ps1`; результаты сохраняются в исключённой из Git папке `outputs/translation-sync-checks`.

Имена разделов и настроек в C# являются идентификаторами сохранённой конфигурации. Сохраняйте эти идентификаторы; отображаемые подписи берутся из `config.*`. Названия музыки, пути файлов и ошибки внешних программ остаются данными. Переводимый текст в C# не добавляйте.
