# Игровые проверки

[English](QA.md)

Инструкция предназначена участникам проекта, которые меняют игровые механики, сеть, звук или интерфейс. Сборка и базовые тесты описаны в [BUILDING.ru.md](BUILDING.ru.md).

Задайте переменные в своей PowerShell-сессии.

| Переменная | Значение |
|---|---|
| `VALHEIM_QA_ROOT` | Папка тестовых данных вне репозитория. |
| `VALHEIM_QA_CLIENT` | Установленная Valheim с Doorstop. |
| `VALHEIM_BEPINEX_CORE` | Совместимая папка BepInEx/core. |
| `VALHEIM_FFMPEG_ROOT` | Дистрибутив с bin/ffmpeg.exe и bin/ffprobe.exe. |
| `VALHEIM_QA_SERVER` | Установленный выделенный сервер для соответствующих сценариев. |
| `VALHEIM_QA_REFERENCE_ALBUM` | Необязательный альбом только для чтения. Отсутствие отмечается пропуском. |

```powershell
./qa.ps1 -Action cases
./qa.ps1 -Action environment-check
./qa.ps1 -Action environment-tests
./qa.ps1 -Action build-candidate
./tools/qa/build-probe.ps1
./qa.ps1 -Action build-gameplay
```

Локальные значения в Git не включайте. `VALHEIM_QA_ROOT` содержит отдельные тестовые профили, входные образцы и результаты вне репозитория. Обычные сохранения и рабочий профиль менеджера модов использовать нельзя. Два локальных клиента используют одну установленную игру.

Команды из примера выводят сценарии, проверяют окружение или компилируют код без запуска Valheim. Полный офлайн-набор запускается через `tests/offline/verify-final.ps1` с параметрами `ProductDll`, `GameManaged`, `BepInExCore`. Исходники находятся в `tests/integration`, `tests/offline` и `tests/reference`. Каталог `tests/cases.json` содержит ID и ссылки на код. Наличие ссылки не означает успешной проверки.

Личные каталоги, музыка и сторонние DLL хранятся только во внешних fixtures. Укажите необходимые входы для соответствующего сценария. Отсутствие обязательного файла не считается успешной проверкой. Необязательный альбом задаётся через `VALHEIM_QA_REFERENCE_ALBUM`; его отсутствие отмечается как пропуск.

Контроллер ограничивает учитываемые данные шестью ГиБ. Три ГиБ выделены runtime, по полтора ГиБ результатам и подготовке пакета. Новая история учитывается как evidence. Отказ по квоте не разрешает удалять прежние материалы.

Игровые действия `local-upgrade-check` и `migration-mp` запускают Valheim. Окно должно быть скрыто, слышимость только собственной тестовой Windows-аудиосессии отключена. Проверьте quiet-статус до сценария. После готовности тестовых мира и персонажа цикл занимает не больше 120 секунд. Холодная загрузка измеряется отдельно. Фокус других приложений не перехватывается.

Указывайте хеш DLL и наблюдаемое поведение. Офлайн-тесты не подтверждают игровой рендер, захват устройства или сетевую сессию. Сохраняйте нужные прежние записи и отчёты для сравнения.
