# Список изменений

[English](CHANGELOG.md)

## [Не выпущено]

## [0.2.6] - 2026-10-20

- Удалены устаревшие указания о приватном репозитории из README установочного пакета.
- Уточнены название кнопки выбора музыки и локальный характер настроек рецептов и стоимости мест украшений.

## [0.2.5] - 2026-10-20

- Виды магнитофона и кассеты открыты сразу и не требуют расходовать эти предметы, в том числе у существующих аппаратов.
- Исправлены включение и сброс плавающего плеера; при его скрытии кнопка выбора музыки остаётся в инвентаре.
- Улучшение аппарата сохраняет геометрию обвесов, а улучшение кассеты больше не запускает полное сохранение персонажа и карты.
- GitHub публикует обычный выпуск с отметкой Latest вместо предварительной альфа-версии.

## [0.2.4] - 2026-10-20

- Скриншоты и полные руководства остаются в GitHub; README установочного пакета ссылается на них.
- Английская и русская документация разделены; локальные настройки крафта отделены от общих настроек хозяина мира.
- Запуск выпуска поддерживает публичные и приватные репозитории без изменения авторизации GitHub.
- Общий переключатель оформления скрывает эффекты паруса лодки, сохраняя помощь движению.

## [0.2.3] - 2026-10-19

### Добавлено

- Выпуск альфа-версии через GitHub Actions с выбором patch/minor/major, облачной сборкой, обновлением версии, тегом и проверкой загруженного архива.

### Исправлено

- Утверждённая иконка кассеты используется в инвентаре, крафте и меню кассеты вместо малоконтрастной миниатюры модели. Один значок обозначает единственный тип кассеты на всех рангах.

## [0.2.2] - 2026-10-18

## [0.2.1] - 2026-10-18

### Добавлено

- Папки локальной музыки, плейлисты, CUE и потоковое воспроизведение.
- Необязательная реакция визуальных эффектов на звук компьютера.
- Восемь уровней аппарата и одна кассета с пятью независимыми цепочками улучшений за трофеи боссов.
- Двадцать четыре места украшений, реагирующие динамики и настраиваемый предпросмотр эффектов.
- Общие бонусы поблизости с настройками баланса хозяина.
- Русский и английский переводы интерфейса.

### Исправлено

- Библиотека музыки восстанавливается из корректной копии при повреждении основного файла.
- Отменённый поиск по каталогу не пересекается с новым поиском.
- Пользовательские рецепты кассет сохраняются при загрузке конфигурации.
- Значения бонусов кассеты учитывают настройки баланса хозяина.
- При завершении захвата звука освобождаются рабочий поток и сигнал остановки.
- При недоступном или несовместимом API Extra Slots используется обычный инвентарь.
