# Происхождение ресурсов

[English](ASSET-CREDITS.md)

Мод содержит три пакета модели и эффектов, три файла калибровок, орнамент Рамсунда, четыре иконки бонусов и иконку кассеты. Собственная работа проекта распространяется по приложенной `LICENSE`. Иконки созданы для проекта с помощью генерации изображений.

Орнамент Рамсунда — адаптация анонимной иллюстрации из *Nordisk familjebok*. На странице Commons указаны участники цифровой обработки и статус public domain; обработка фрагмента выполнена в проекте. [Источник](https://commons.wikimedia.org/wiki/File:Sigurd.svg).

Для неподвижных надписей использовался Segoe UI Historic. Распространяются готовые модели и текстуры без файлов шрифта. [FAQ Microsoft о шрифтах](https://learn.microsoft.com/en-us/typography/fonts/font-faq). Шрифты интерфейса и трофеи Valheim берутся из установленной игры во время работы. Valheim и графика игры на скриншотах принадлежат соответствующим правообладателям. Это неофициальный мод.

FFmpeg и ffprobe распространяются отдельно по LGPL-2.1-or-later. Лицензия, уведомление, хеши, соответствующие исходники и инструкции находятся в `Tools/FFmpeg`. Личная музыка в пакет не входит.
