# Происхождение ресурсов

[English](ASSET-CREDITS.md)

Мод содержит три пакета модели и эффектов, три файла калибровок, орнамент Рамсунда, четыре иконки бонусов и иконку кассеты. Собственная работа проекта распространяется по приложенной `LICENSE`. Иконки созданы для проекта с помощью генерации изображений.

Орнамент Рамсунда — адаптация анонимной иллюстрации из *Nordisk familjebok*. На странице Commons указаны участники цифровой обработки и статус public domain; обработка фрагмента выполнена в проекте. [Источник](https://commons.wikimedia.org/wiki/File:Sigurd.svg).

Для неподвижных надписей использовался Segoe UI Historic. Распространяются готовые модели и текстуры без файлов шрифта. [FAQ Microsoft о шрифтах](https://learn.microsoft.com/en-us/typography/fonts/font-faq). Шрифты интерфейса и трофеи Valheim берутся из установленной игры во время работы. Valheim и графика игры на скриншотах принадлежат соответствующим правообладателям. Это неофициальный мод.

FFmpeg и ffprobe 7.1.5 являются отдельными программами и не покрываются MIT-лицензией мода. Авторы разрешают LGPL 2.1 или любую более позднюю версию. Для этого распространения Max Smirnov (Rizias) выбирает LGPL 3.0 или более позднюю версию согласно разделу 13 LGPL 2.1. В `Tools/FFmpeg` сохраняется исходный текст LGPL 2.1 и добавлены полные тексты LGPL 3.0 и GPL 3.0, уведомление и исходный манифест сборки.

Каждый выпуск GitHub предоставляет отдельный `FFmpeg-Sources.zip` с полными исходниками, точными скриптами сборки и патчем response-file для `ffbuild/library.mak` от 2026-10-20. Кодеки не изменялись. Установочный README и уведомление содержат прямую ссылку на исходники именно этой версии. При распространении программ, включая другие площадки, доступ к исходникам должен сохраняться согласно разделу 6(d) GPL 3.0, включённой в LGPL 3.0. Программы можно пересобрать или заменить. Личная музыка в пакет не входит.

Уведомления также сохраняют сведения о стороннем коде FFmpeg, MinGW-w64, MIT/BSD-лицензии winpthreads и исключение GCC Runtime Library Exception 3.1 вместе с GPL 3.0. Программы FFmpeg частично основаны на работе Independent JPEG Group. Скрипты сборки проекта и патч response-file распространяются по MIT; её текст включён в архив исходников.
